# 3. Add GA4 to the website

Since your website is React + Vite, I recommend using Google's official Google tag rather than adding a random analytics package just for basic tracking.

You can place the Google tag in your main HTML document, typically:

```text

```

You'll get code from Google that looks roughly like:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
```

Replace:

```text
G-XXXXXXXXXX
```

with your actual Measurement ID.

**Use the exact Google-generated snippet rather than copying one from somewhere else.**

If someone navigates:


without the browser doing a full page reload, GA4 still needs to understand that those are page views.

So we should make sure **SPA page navigation is tracked correctly**.

Don't blindly add `gtag('config', ...)` every time React renders.

# 7. Don't track sensitive information

This is **very important**.

Never send personally identifiable information to Google Analytics.

For example, don't send:

```text
email
phone number
client name
message content
password
verification code
```

as Analytics event parameters.

Bad:

```js
gtag('event', 'contact_form_submit', {
  email: user.email
});
```

Don't do that.

Instead:

```js
gtag('event', 'contact_form_submit');
```

or use non-identifying metadata such as:

```js
gtag('event', 'contact_form_submit', {
  service: 'short_form_video'
});
```

provided that value itself isn't sensitive.

# 10. Connect Google Search Console

This is the next thing I'd do after GA4.

GA4 tells us:

> **What visitors do on the website.**

Search Console tells us:

> **How Google Search finds and indexes the website.**

So together:

```text
Google Search Console
        +
Google Analytics
        ↓
Alpha Cut website insights
```

In Search Console, add:

```text
alpha-cut.com
```

I'd recommend using a **Domain property**, not just:

```text
https://alpha-cut.com/
```

because Domain property can cover the domain's subdomains and protocols.
